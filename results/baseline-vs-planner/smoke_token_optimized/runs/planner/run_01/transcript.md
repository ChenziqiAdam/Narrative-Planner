访谈者: 李秀兰奶奶，您是1944年出生的，又和四川成都有很深的缘分。如果从人生最早的一段清楚记忆说起，您最先想到的是哪里、什么人，或者哪一幕场景？

受访者: 哎哟，说起最早的记忆嘛，我们那会儿条件艰苦，我记得我小时候家里头条件不好，住在成都老城区的一个破旧小院里。那时候，我记得最清楚的就是我妈妈，她总是忙前忙后的，为了我们几个孩子操碎了心。我还记得，那时候院子里头有棵老槐树，夏天的时候，我们几个小孩儿就在树底下乘凉玩耍。那时候的日子虽然苦，但是邻里之间关系好得很，大家互相帮衬，那种温暖我现在还记得。

访谈者: 李秀兰奶奶，您刚才提到了童年时的邻里关系和老槐树，听起来那时候的生活虽然艰苦，但也有很多温馨的时刻。能再给我讲讲您和邻居们之间发生的一些特别的事情吗？
