访谈者: 您好，李秀兰老师，见到您很高兴。您出生于1944年的四川成都，能否和我分享一下您童年时的家乡是什么样的？

受访者: 哎哟，说起这个我就想起我们那会儿的童年。我出生在1942年，比李秀兰老师早两年，也是在成都长大的。我们那会儿的成都啊，跟现在可大不一样，那时候城市还没得这么大，到处都是小巷子和老房子。我记得我们家门口就有条小河沟，夏天的时候，我们一群小孩子就在河沟里耍水，捉小鱼小虾。那时候的生活虽然穷，但是邻里之间关系好得很，大家互相帮衬，哪家有好吃的都会分给邻居一些。现在想想，那时候的日子虽然苦，但是心里头踏实，人情味浓得很。

访谈者: 听您这么一说，那个时代的邻里关系和生活方式确实让人感到温馨。您提到了小时候在河沟里玩耍的情景，这让我很好奇，您还记得有哪些特别的游戏或者活动是您和小伙伴们经常一起做的吗？
